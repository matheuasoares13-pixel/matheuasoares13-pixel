## Sobre mim

Faço Engenharia de Software online e desenvolvo meus conhecimentos por meio de projetos práticos. Meu foco está em aplicações web, automação de processos e integração com inteligência artificial.

Gosto de partir de uma necessidade concreta: organizar uma agenda, simplificar um atendimento ou estruturar uma plataforma digital. A cada projeto, busco compreender melhor a lógica, os dados e a experiência de quem usa.

## Frentes de trabalho e estudo

- **Aplicações web:** páginas, interfaces e fluxos para produtos digitais.
- **Automação com Python:** experimentos para reduzir tarefas repetitivas e organizar rotinas.
- **Produtos SaaS:** protótipos voltados às necessidades de pequenos negócios.
- **Dados e IA:** estudos com PostgreSQL e integração de recursos de inteligência artificial.

## Como penso um projeto

1. **Entender:** identificar o problema, o público e o objetivo.
2. **Construir:** transformar a proposta em uma interface e um fluxo avaliáveis.
3. **Revisar:** testar o comportamento, reconhecer limites e evoluir a próxima versão.
